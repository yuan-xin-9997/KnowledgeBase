# AI 接入需求规格说明书

## 目标

在保留现有网页会话、用户隔离和业务规则的前提下，为 AI 与自动化程序提供版本化 API、远程 MCP 服务和网页凭据管理入口。

## 功能范围

- API：文档查询、来源查询/创建/修改、异步同步、任务进度和结果。
- MCP：与 API 共用业务层的查询和安全写入工具；默认不开放删除、批量修改、发布和模型密钥管理。
- 网页：设置体系中的「AI 接入」页面，支持凭据创建、一次性密钥展示、分页列表、撤销、地址和示例、无副作用连接测试。
- 凭据：名称、过期时间、scope、摘要存储、撤销和短期 OAuth token。

## 权限与安全要求

- 匿名、空、错误、过期、撤销凭据不得访问业务数据。
- 凭据始终映射到所属用户，并在每次请求重新检查用户是否启用和当前角色；角色降低后不能继续执行管理员业务。
- 用户只能管理自己的凭据；管理接口仅接受网页会话，不接受 Bearer 凭据。
- 完整密钥仅创建响应返回一次，禁止缓存；页面只在内存中保存到用户关闭提示。
- 写操作记录身份、动作、目标、结果和时间，不记录密钥、密码或敏感正文。
- 机器写操作要求幂等键；MCP 写工具要求显式确认。

## 验收标准

- 自动化测试覆盖凭据状态、越权、所有者隔离、降权/停用、分页、并发幂等、任务恢复和 MCP 官方客户端。
- 真实浏览器完成创建、复制提示、列表、无副作用测试和撤销；撤销后调用立即返回 401。
- 生产部署提交、备份、systemd 状态和实际地址均需核验。
